## 📥 Installation & Setup

### 1️⃣ Install Node.js and npm
Download and install Node.js from the official website:

https://nodejs.org/

Verify installation:

```bash
node -v

3️⃣ Install Dependencies
npm install
4️⃣ Run the Project Locally
npm start
